# BakeNest
#### DEVOPS Project Part 1
- Ellisza, Aniq, Irfan, Akanksha

## Database
- `bakenest-db.json` – Live database (server reads and writes here).
- `bakenest-db-template.json` – Template for automatically creating the database.
- `localStorage` – Stores saved recipes in the browser.

## How To Run
1. Open the project folder in VS Code.
2. Run `npm install` in the main project folder (first time only).
3. Run `node server.js`.
4. Open http://localhost:3000.

**Note:** The database is created automatically if missing. Do not use Live Server.
